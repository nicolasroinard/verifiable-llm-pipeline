The internal run was completed and evidence of the run is retained internally.

## Use as Reference

This demo can be referenced as a pattern for:
- Documenting document processing workflows
- Illustrating entity extraction and lineage tracking
- Demonstrating deterministic validation approaches
- Showing output structuring patterns

But should not be treated as:
- A complete replication of the internal run
- An exposure of internal infrastructure
- A certified or guaranteed outcome
- A production-grade pipeline
